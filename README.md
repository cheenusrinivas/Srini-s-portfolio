# 🖥️ My Developer Portfolio — How I Built It

A personal portfolio website built from scratch using React.js, 
showcasing my projects, skills, and experience as a 
Full-Stack Software Engineer based in Dublin, Ireland.

🌐 **Live:** [srinivasudhayasankarportfolio.netlify.app](https://srinivasudhayasankarportfolio.netlify.app)

---

## 🛠️ Built With

| Tool | Purpose |
|---|---|
| React.js | Frontend framework — built as a single page app |
| JavaScript (ES6+) | Core programming language |
| HTML5 & CSS3 | Structure and base styling |
| Inline CSS / Style props | Component-level styling in React |
| Intersection Observer API | Scroll-triggered fade-in animations |
| React Hooks (useState, useEffect, useRef) | State management and side effects |
| Create React App | Project setup and build tooling |
| Netlify | Free hosting and auto-deployment |
| Git & GitHub | Version control and source code hosting |

---

## ✨ Features

- **Smooth scroll animations** — sections fade in as you scroll down
  using the Intersection Observer API
- **Custom cursor** — purple ring cursor that grows on hover
- **Responsive design** — works on desktop, tablet and mobile
- **Interactive navbar** — smooth scrolling to each section
- **Contact form** — with send confirmation animation
- **Noise texture overlay** — subtle design detail for depth
- **Hover effects** — on every card, button and link
- **Stats section** — highlights key achievements in the hero

## 🚀 How to Run Locally

```bash
# Clone the repo
git clone https://github.com/cheenusrinivas/Srini-s-portfolio.git

# Go into the folder
cd Srini-s-portfolio

# Install dependencies
npm install

# Start the dev server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 How to Deploy

This portfolio is deployed on **Netlify** for free.

```bash
# Build the production version
npm run build

# Deploy to Netlify
# Drag and drop the build/ folder to drop.netlify.com
# OR connect your GitHub repo on app.netlify.com
# for automatic deployments on every git push
```

## 🎨 Design Decisions

- **Dark theme** — easier on the eyes, looks more modern
  and professional for a developer portfolio
- **Purple accent colour (#7c3aed)** — stands out without
  being too loud
- **Georgia serif font** — gives an editorial, premium feel
  different from typical developer portfolios
- **One page layout** — recruiters spend 30 seconds on a 
  portfolio, everything visible without clicking between pages
- **Minimal dependencies** — no UI libraries used, 
  everything built from scratch to demonstrate CSS skills
